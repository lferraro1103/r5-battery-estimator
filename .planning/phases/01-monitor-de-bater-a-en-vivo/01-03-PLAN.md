## Phase Goal

**Como** propietario de un R5 Ultra, **quiero** consultar una bandeja y un panel honestos y accesibles en una instalación Windows real, **para** confiar en la lectura y saber cuándo está antigua o temporalmente no disponible.

<objective>
Cerrar la experiencia de Phase 1 con el contrato exacto de bandeja D-01–D-05, todos los estados del panel, un bundle NSIS y una matriz de aceptación Windows/hardware que no confunda automatización con evidencia física.

Purpose: Convertir el runtime probado en una capacidad visible, instalable y evaluable contra el receptor, el software oficial y juego real.
Output: UI accesible, iconos/bundle, pruebas de componente, harness de hardware y registro de aceptación reproducible.
</objective>

## Planner Assumptions and Acceptance Predicates

| ID | Unresolved requirement assumption | Concrete predicate used by this plan |
|---|---|---|
| PA-BATT-01 | A live snapshot is understandable when all facts appear together. | Connected panel and menu show percent, Cargando/En descarga and a localized last-valid timestamp; both expose the same revision in test hooks/diagnostics. |
| PA-BATT-02 | Cause plus age is more honest than a guessed sleep state. | Disconnected, temporarily unavailable and stale each have distinct text; if a prior reading exists it remains visible with `hace N min`, otherwise no percent is rendered. |
| PA-BATT-03 | Bounded reenumeration is acceptable recovery. | On target hardware, wake, reconnect and resume regain a valid reading without app restart within the 15-minute capped retry window; actual elapsed results are recorded. |
| PA-EST-01 | Whole hours are the maximum honest precision for the marketing-derived seed. | The panel and connected tooltip show whole hours plus `provisional`; no minutes, confidence percentage or calibrated wording appears. |
| PA-UI-01 | A compact native menu is the fastest useful surface. | Left click reveals textual status, provisional autonomy and Abrir panel within one second; the action opens/focuses a window containing the same revision. |
| PA-WIN-02 | Structural limits plus measured baseline and perception close the safety requirement. | One process/worker, 300 s normal cadence, zero overlaps, hidden CPU ≤0.5%, hidden working set ≤120 MiB, HID p95 ≤500 ms, and a 20-minute 8 kHz A/B play session reports no perceptible added latency or dropped input. |
